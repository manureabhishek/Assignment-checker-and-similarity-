Core Engine DSA Components

All algorithms and data structures implemented natively inside main.cpp

1

Stack: Bracket Checking

Validates grammatical bracket balance for (), [], and {} using LIFO stack semantics before execution.

O(N) Time • O(N) Space
2

Hash Table: Expected Lookup

Custom chained hash table using polynomial rolling hash with prime modulus for O(1) average expected output retrieval given test case inputs.

O(1) Average Lookup
3

FIFO Submission Queue

Guarantees fair initial scheduling of student files discovered in submissions/ in order of ingestion.

First-In First-Out
4

Max Heap: Priority Queue

Schedules compilation and testing prioritizing larger source files first using a binary max-heap with heapifyUp and heapifyDown.

O(log N) Priority Scheduling
5

Tree: Simplified Block Structure

Constructs a tree representation with ROOT and BLOCK nodes corresponding to {} scope blocks and token grouping. (Simplified structural model, not a full compiler AST).

Scope Block Decomposition
6

Graph: Consecutive-Token Graph

Builds a directed transition graph connecting adjacent consecutive code tokens (token[i] -> token[i+1]) to measure structural adjacency similarity (not actual runtime control flow).

Token Transition Graph
Σ

Weighted Structural Similarity Formula

Combined formula: Overall = 0.50 × TokenSim + 0.25 × TreeSim + 0.25 × GraphSim. Pairs scoring ≥ 70% generate automated alerts.

50% Token + 25% Tree + 25% Graph
